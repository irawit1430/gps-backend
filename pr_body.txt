💡 **What:** The optimization replaces the sequential loop of `axios.post` requests in `simulateFleet` with a single `Promise.all` containing an array of mapped `axios.post` promises.

🎯 **Why:** In the original code, each telemetry request awaited the completion of the previous one. The network latency was cumulative, limiting the speed at which telemetry data could be sent during simulations and artificially slowing it down.

📊 **Measured Improvement:** I ran a local benchmark simulating 50 buses making telemetry requests with 50ms of network latency each.
- **Baseline (Sequential):** 2678ms
- **Optimized (Parallel):** 144ms
- **Improvement:** 18.60x speedup
